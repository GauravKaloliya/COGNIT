C.O.G.N.I.T. API Documentation

Production API Reference

Overview

Production API surface for participant onboarding, payment verification, image delivery, and survey submission workflows.

Base URL

{{ base_url }}

Core Flow

  1. Create participant with /participants.
  2. Record consent with /consent.
  3. Create payment with /payments/create and verify via /payments/{payment_id}/verify-upload.
  4. Fetch image from /images/random.
  5. Submit response through /submit.

General Rules

  • Use JSON request bodies with Content-Type: application/json.
  • Rate limits apply per route.
  • Response timestamps are UTC ISO 8601.

Record participant consent.

Survey

GET /images/random?exclude=img1,img2 ▶

Fetch random image for participant.

POST /submit ▶

Submit survey/image response.

Rate Limit: 60 per minute

POST /engagement/track ▶

Track participant engagement events.

Rate Limit: 60 per minute

Payments

POST /payments/create ▶

Create payment session and get UPI details.

Rate Limit: 20 per minute

GET /payments/{payment_id}/status ▶

Check payment status and remaining time.

Rate Limit: 30 per minute

POST /payments/{payment_id}/verify-upload ▶

Verify payment screenshot upload.

Rate Limit: 20 per minute

Request Body

{
  "image_base64": "base64-encoded-image-data",
  "file_extension": "jpg",
  "sha256": "sha256-hash"
}
