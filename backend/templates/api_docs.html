Overview

This document includes only routes used by end users through the web app flow.

Response Envelope

{
  "success": true,
  "data": { ... },
  "message": "optional"
}
{
  "success": false,
  "error": {
    "code": "PAY_001_0004",
    "message": "Human-readable message",
    "category": "PAY",
    "http_status": 400,
    "retryable": true,
    "request_id": "uuid"
  }
}

Core Flow

  1. Create participant: POST /participants
  2. Availability checks while filling form: /check-username, /check-email, /check-phone
  3. Record consent: POST /consent
  4. Create payment and verify screenshot: POST /payments/create then POST /payments/{payment_id}/verify-upload
  5. Fetch image: GET /images/random
  6. Submit response: POST /submit

General Rules

  • Use Content-Type: application/json for POST routes.
  • Use X-Idempotency-Key on mutating routes to avoid duplicate writes.
  • Use X-Request-ID from response headers for support/debugging.
  • All timestamps are ISO-8601 UTC strings.

Examples

Minimal Frontend Flow

// 1) Create participant
const participant = await fetch('/participants', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    username: 'user_123',
    email: 'user@gmail.com',
    phone: '9876543210',
    gender_code: 'male',
    age: 25,
    location: 'ahmedabad',
    language_code: 'en',
    prior_experience: 'some experience'
  })
}).then(r => r.json());

// 2) Consent (idempotent)
await fetch('/consent', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'X-Idempotency-Key': crypto.randomUUID(),
  },
  body: JSON.stringify({ public_id: participant.data.public_id }),
});

// 3) Create payment
const payment = await fetch('/payments/create', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'X-Idempotency-Key': crypto.randomUUID(),
  },
  body: JSON.stringify({ public_id: participant.data.public_id, amount: 1 }),
}).then(r => r.json());

Common Error Codes

  • VAL_001_0001: Missing required fields
  • PAR_001_0001: Participant not found
  • PAY_001_0001: Payment not found
  • PAY_001_0002: Payment expired
  • PAY_001_0003: Payment invalid state
  • PAY_001_0004: Invalid payment screenshot / verification failed
  • SUB_001_0003: Description length invalid
  • SUB_001_0004: Feedback length invalid
  • SUB_001_0005: Rating invalid
  • RATE_001_0001: Rate limit exceeded
