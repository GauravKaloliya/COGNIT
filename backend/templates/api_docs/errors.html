Errors

Drive client behavior by error.code. Retry only when error.retryable=true.

Validation

  • VAL_* invalid payload, missing fields, or wrong format.
  • Fix payload, then retry with a new request.

Rate Limit

  • RATE_LIMIT_EXCEEDED temporary throttle.
  • Retry with exponential backoff and jitter.

System

  • SYS_* backend transient/operational failure.
  • Safe to retry if request is idempotent.

Payment

  • PAY_* payment flow/session consistency issues.
  • Re-check payment status before retrying.

Fraud

  • FRAUD_* verification mismatch or suspicious upload.
  • Require a fresh compliant screenshot.

Tracing

  • Capture and store X-Request-ID from every failure.
  • Use error contract as source of truth.
