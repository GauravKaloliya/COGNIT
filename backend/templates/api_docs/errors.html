Errors

Use error.code for client behavior. Respect error.retryable and log error.request_id on every failure.

Validation

  • MISSING_FIELDS, INVALID_UUID, INVALID_AMOUNT, DESCRIPTION_LENGTH, RATING_INVALID, WORD_COUNT.
  • Send corrected payload and retry with new idempotency key when required.

Bot/Rate

  • BOT_CHALLENGE_FAILED when Turnstile token validation fails.
  • RATE_LIMIT_EXCEEDED temporary throttle.
  • Retry with fresh token (if bot check) and exponential backoff.

System

  • DATABASE_ERROR, INTERNAL_ERROR, SYS_INTERNAL_ERROR, SYS_SERVICE_UNAVAILABLE.
  • Retry only for idempotent operations; include request_id in support logs.

Payment

  • PAY_INVALID_SHA256, PAY_INVALID_IMAGE_TYPE, PAYMENT_NOT_FOUND, PAYMENT_INVALID_STATE, PAYMENT_EXPIRED.
  • Call GET /payments/{payment_public_id}/status before retrying verify/upload actions.

Fraud

  • DUPLICATE_IMAGE, DUPLICATE_IMAGE_SELF, REJECTED_REUSE.
  • Require new payment screenshot and do not reuse previously rejected files.

State/Access

  • PARTICIPANT_NOT_FOUND, CONSENT_REQUIRED, FLAGGED_ACCOUNT, PAYMENT_INVALID_STATE.
  • Drive UI flow transitions from backend status instead of local-only state.
