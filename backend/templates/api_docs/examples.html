Examples

Production-oriented request and response samples.

Create Participant

curl -X POST "{{ base_url }}/participants" \
  -H "Content-Type: application/json" \
  -H "X-Idempotency-Key: 4e30a6e4-1d57-4e95-a9ce-0fd6f6f6f13a" \
  -d '{
    "username": "demo_user",
    "email": "demo@example.com",
    "phone": "9876543210"
  }'

Create Payment Session

curl -X POST "{{ base_url }}/payments/create" \
  -H "Content-Type: application/json" \
  -H "X-Idempotency-Key: 1b667f94-8c42-4a45-b0f9-f7fcb677ff90" \
  -d '{
    "public_id": "ptcp_123",
    "amount": 1
  }'

Fetch Survey Image

curl -X GET "{{ base_url }}/images/random?public_id=ptcp_123"

Submit Survey Response

curl -X POST "{{ base_url }}/submit" \
  -H "Content-Type: application/json" \
  -H "X-Idempotency-Key: f0fd6a0f-c2f9-4318-b9f6-77e75c7e5f0f" \
  -d '{
    "public_id": "ptcp_123",
    "image_id": "img_239",
    "description": "A busy urban scene with layered activity and movement...",
    "complexity": 4
  }'
